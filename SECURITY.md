# Security Policy

This software is experimental. Do not use it with production wallets or real
funds.

Report a security problem with
[GitHub private vulnerability reporting](https://github.com/ADGLx/midnight-mobile/security/advisories/new).
Do not use a public issue, pull request, discussion, or integration report.

Include the following information in the report:

- State the affected version or commit.
- State the affected platform and environment.
- Describe the possible effect of the problem.
- State the access that an attacker needs.
- Provide a small, deterministic test that uses synthetic data.
- Describe a possible fix or a way to reduce the risk, if one is known.
- State whether another party has disclosed the problem.

Do not send real keys, seeds, checkpoints, credentials, private service URLs,
transactions, wallet identifiers, or sensitive logs. Redact local paths and
unrelated identifiers. Ask maintainers for a safe transfer method before you
send any sensitive data.

Test only systems and data that you own or have permission to test. Stop testing
if you find real wallet material or credentials. Do not damage data. Do not
reduce service availability. Do not test public network services without
permission from the service operator.
