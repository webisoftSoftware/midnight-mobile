# Unofficial Project Disclaimer

Midnight Mobile is an experimental, community-maintained project developed by
1AM contributors. It is not an official Midnight SDK and is not affiliated with,
sponsored by, approved by, or endorsed by the Midnight Foundation or the
operators of the Midnight network.

References to Midnight, Expo, React Native, Apple, Android, and other projects
or products identify intended interoperability only. All names, marks, and
trademarks belong to their respective owners.

The project is under active development and has not reached a production-ready
release. APIs, checkpoint formats, native packaging, compatibility, and security
assumptions may change during the alpha program. No statement in the roadmap is
a promise that a feature or release will ship.

The SDK does not provide operated indexer, proof, or node services. Adopters
must select and configure their own endpoints, evaluate those services' security
and privacy properties, and protect their own credentials and wallet material.
The project does not provide financial, legal, custody, or security advice.

Before using a release, review its license, compatibility record, known
limitations, provenance, security policy, and checksums. Use the software only
in environments appropriate for experimental wallet software and independently
assess whether it meets your requirements.
